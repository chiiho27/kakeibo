# 週ごとの生活費の表示仕様

週単位では日常の支出調整、月単位では家計全体の把握を行う。

- 生活費は「支出（変動費）」のうち費目管理の「週管理」がオンの費目。名称・件数は設定から表示し、固定しない。
- ホームと月別レポートの週集計は同じ対象費目を使用する。対象費目の開閉一覧はレポートだけに表示し、「週管理に設定したN費目」と読点区切りの費目名を示す。
- 週は月曜始まりで月内に区切る。月初の端数を1週目、6週目相当の日を5週目に含める。
- 週予算は対象費目の月予算×週内の月の日数÷月の日数。内部計算は丸めず、円表示時のみ丸める。
- 週の残額は週予算−対象実績。マイナスも表示し、余り・超過を翌週へ繰り越さない。
- ホームの見出しは「今週の残予算」。今週の残予算と今月の生活費残予算を並べ、直後に今月の記録ベース収支を表示する。
- 週予算は日割りの目安として説明する。予算残額は預金・口座残高を意味しない。
- 月別レポートは同期済み正本のコピーで集計する。未送信の追加・修正・削除は含めない。
- ホームの生活費は端末内の未送信分を含む暫定表示。記録ベース収支は同期済みを主表示し、未送信があれば暫定収支を併記する。
- 月別の変動費内訳・予算・実績・残予算には、週管理対象外とマスターにない過去の費目も含める。
- 週管理対象がなければ未設定を表示し、全変動費への自動切替はしない。
- 過去月の固定済み月予算は既存の取得値を使う。週管理対象の履歴は保持せず、シートと同様に現在の設定を使う。

実装時に費目マスター、予算額、シートの数式、取引データは変更しない。テストは架空の予算・取引を使う。

- 固定費はレポートに月予算合計と使った額を表示。過去月は予算を保存していないため「記録なし」とし、現在の予算を過去の予算として表示しない。
- 週グラフの実績・予算・残額は14pxで統一し、超過時も色だけを変える。
