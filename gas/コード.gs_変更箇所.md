# コード.gs（カード明細取込）の変更箇所

コード.gs はリポジトリに置いていません（個人の設定を含むため）。Apps Script のエディタで、次の3か所を書き換えてください。
アプリAPI.gs を新しい版にしてから行います（`kkbApiSetHimokuRules_` などはアプリAPI.gs の関数です）。

## 1. CSV読込：費目の入力規則（readCardCsvFiles、174行目あたり）

`for (let i = 0; i < allRows.length; i++) {` の行（`const feeCandidates = sheet.getRange(row, 15, 1, 29);` の2行上）の**直前**に、次の1行を足します。

```js
      if (!kkbApiSetHimokuRules_(sheet, startRow, allRows.length, 7, 8))
```

移行後は区分ごとの一覧を入力規則にし、移行前（または元に戻したあと）は今までどおり O:AQ を使います。

## 2. 反映前の照合：費目の候補（applyApprovedCardRows、257行目あたり）

```js
    const feeCandidates = r.slice(14, 43).map(v => String(v || '').trim()).filter(Boolean);
```

を次に置き換えます。

```js
    const feeCandidates = kkbApiMasterOn_() ? kkbApiCandidates_(ss, category) : r.slice(14, 43).map(v => String(v || '').trim()).filter(Boolean);
```

## 3. 01_Raw_Data への書込（applyApprovedCardRows、301〜315行目）

`const startRow = findFirstBlankByColumn_(raw, 5, 2);` から
`card.getRangeList(sourceRows.map(row => 'K' + row)).setValue('取込済');` までを、次に置き換えます。

直す理由：

- 今は「最初の空行から続けてまとめて」書くため、アプリで途中の行を削除してできた空行が短いと、その下の取引を上書きします。
- 費目の書込で失敗すると、費目が空の行が残ります。

```js
  // 01_Raw_Data の空き行（削除でできた途中の空行も含む）に1行ずつ入れる。下の行は上書きしない。
  const blanks = [];
  raw.getRange(5, 2, KKB_API.LAST_ROW - 4, 1).getDisplayValues().forEach((v, i) => { if (!v[0]) blanks.push(5 + i); });
  if (blanks.length < approved.length) {
    ui.alert('01_Raw_Data に空きの行が足りません（必要 ' + approved.length + '行・空き ' + blanks.length + '行）。何も書いていません。');
    return;
  }
  const rawRows = approved.map((_, i) => blanks[i]);
  // 先に区分を含む列を書き、区分に合う費目の候補にしてから費目を書く。途中で失敗したら書きかけの行を空に戻す。
  try {
    approved.forEach((r, i) => {
      raw.getRange(rawRows[i], 2, 1, 3).setValues([[r[0], r[1], r[2]]]);
      raw.getRange(rawRows[i], 6, 1, 4).setValues([[r[4], r[5], r[6], r[7]]]);
      raw.getRange(rawRows[i], 12).setValue(r[8]);
      kkbApiSetHimokuRules_(raw, rawRows[i], 1, 4, 5);
    });
    SpreadsheetApp.flush();
    approved.forEach((r, i) => raw.getRange(rawRows[i], 5).setValue(r[3]));
    SpreadsheetApp.flush();
  } catch (err) {
    rawRows.forEach(row => { raw.getRange(row, 2, 1, 8).clearContent(); raw.getRange(row, 12).clearContent(); });
    SpreadsheetApp.flush();
    ui.alert('反映できませんでした。書きかけの行は空に戻しました：' + (err && err.message || err));
    return;
  }
  card.getRangeList(sourceRows.map(row => 'K' + row)).setValue('取込済');
```
